# Data protocol

The published snapshot documents pinned analytical PhysicsTM observations and deterministic population construction in [Phase 1](phase1.md), and channelization and clean-training normalization in [Phase 2](phase2.md). Task-specific adapters and execution limits are described in [classifier](phase4.md), [S1](phase6.md), [S2](phase7.md), and [S3](phase8.md) records. These records distinguish reference-fixture execution from production population definitions; their presence does not establish historical dataset reproduction. See [Phase 11](phase11.md) for the final reproducibility boundary.
