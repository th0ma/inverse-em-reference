# Phase 4: source-count classifier

Phase 4 implements the bounded mechanism for the five-class (`S=1..5`, label `S-1`) source-count classifier. It does not authorize or perform scientific population generation, scientific training, sealed evaluation, or robustness evaluation.

The model is a CPU float64 circular 1-D residual network with input `(B,4,30)`, 64 hidden channels, four two-convolution residual blocks, one dropout (`p=0.1`) per block, adaptive average pooling, and a five-logit linear head. Its exact trainable parameter count is 99,973. Initialization reproduces the historical state digest `e97893358d9633d3d693b56c15bdef5edea56ee8d68a06861ef144a322ade925` while preserving caller Torch RNG state.

The data path reuses Phase 1 populations and PhysicsTM and Phase 2 channelization, clean-training normalizer, and raw-complex training noise. Noise is applied after complex source superposition and before channelization and normalization. Validation is clean. Interfaces reject SEALED roles before any generation or traversal.

Minibatch order uses the recovered SHA-256-keyed PCG64DXSM epoch permutation. Dropout uses standard `torch.nn.Dropout` with the new reference-repository owned seed `2757741876565858931`, derived from SHA-256 of `inverse-em-reference|phase4|classifier|dropout|20261903`. This is not a historical dropout seed. Its state is isolated from and preserves caller Torch RNG state.

Training uses mean unweighted cross entropy, Adam, clean full-validation macro-F1, ReduceLROnPlateau, strict BEST replacement on any numerical macro-F1 increase, and a separate `1e-4` early-stopping reference. The implementation runner is deliberately capped at 100 training and 100 validation records and two epochs. BEST and resumable checkpoints are descriptive reproducibility artifacts, not authorization objects. Every checkpoint load requires an explicit complete scientific compatibility context; frozen model/input identities and runtime normalizer, Physics, population-role, RNG-contract, and PyTorch identities are mandatory checks rather than optional caller assertions.

Phase 4 accepts classifier population metadata only when its role and frozen seed agree (`TRAINING`/`20261901` or `VALIDATION`/`20261902`). Reserved sealed and robustness seeds cannot be relabeled. Observation transforms also require a `FrozenChannelNormalizer` whose task is exactly `CLASSIFIER`.
